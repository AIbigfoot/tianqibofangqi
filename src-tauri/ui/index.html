联网导入

粘贴列表页 / 搜索页地址（每行一个），由 yt-dlp 解析出条目与封面：条目进入海报墙， 封面缓存在本机海报目录；点击条目即在线播放（播放时实时解析流地址）。 需要把 yt-dlp.exe 放在主程序同目录（或加入系统 PATH）。

元数据数据源

按番号从数据源刮削：全名（番号 + 标题）、封面、截图、标签（类别 / 系列 / 片商 / 导演 / 演员）、 发行日期、演员、十条高赞短评与预告片。全部内容保存在本机。

获取步骤：浏览器登录站点 → 按 F12 打开开发者工具 → 切到 Network（网络）→ 任选一个请求 → 复制请求头里 Cookie 的完整值粘贴到上面。 不填 Cookie 也能刮削标题、封面、截图、标签、日期与演员；短评与预告片需要登录。
